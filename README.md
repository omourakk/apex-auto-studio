# APEX Auto Studio — demonstração de estética automotiva

Site completo em HTML, CSS e JavaScript, com conteúdo dirigido ao consumidor final de uma estética automotiva. Marca fictícia.

## Visualizar
Abra `index.html` no navegador, ou execute `python -m http.server 8000` e visite `http://localhost:8000`.

## Publicar
Envie os arquivos ao repositório GitHub e publique pelo GitHub Pages (Settings → Pages → Deploy from branch → main, /root) ou Cloudflare Pages (upload estático).

## Antes de vender a um negócio real
Substitua nome, fotos por imagens autorizadas, serviços e descrições confirmados, informações de contato e conecte um canal de atendimento real. Remova a identificação de projeto fictício somente quando os dados corresponderem a um negócio real. O formulário atual apenas gera uma mensagem local para copiar: **não envia dados**.

As imagens são ilustrativas e carregadas da internet; não representam serviços realizados.
